## Where help is most wanted

- **Editing UI for preserved features**: bones and skinning, meshes, constraints, nested artboards, blend states, layouts, events
- **Data binding**: view model editing in the editor (preview already supports it)
- **Font subsetting** to shrink files with text
- **Templates** that teach one Rive feature each
- **Translations** of the docs
- **File compatibility**: `.riv` files that don't round-trip or render differently (open an issue with the file)
