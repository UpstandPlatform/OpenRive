# Keyboard shortcuts

Every shortcut can be changed: press `?` (or Menu › Keyboard shortcuts), click a shortcut and press the new keys.
Custom bindings are saved in your browser. On macOS, `Ctrl` means `⌘`.

## File

| Action | Keys |
| --- | --- |
| Save | `Ctrl S` |
| Export .riv | `Ctrl E` |
| Export preview bundle (.zip) | `Ctrl Shift E` |
| Convert inputs to data binding | — (canvas menu) |
| Open preview | `Ctrl P` |
| Keyboard shortcuts | `?`, `Ctrl /` |
| Preferences | `Ctrl ,` |

## Edit

| Action | Keys |
| --- | --- |
| Undo / Redo | `Ctrl Z` / `Ctrl Shift Z`, `Ctrl Y` |
| Cut / Copy / Paste | `Ctrl X` / `Ctrl C` / `Ctrl V` |
| Paste in place | `Ctrl Shift V` |
| Duplicate | `Ctrl D` |
| Delete | `Delete`, `Backspace` |
| Select all | `Ctrl A` |
| Deselect / step out of a group | `Esc` |
| Rename | `F2` |

## Object

| Action | Keys |
| --- | --- |
| Group / Ungroup | `Ctrl G` / `Ctrl Shift G` |
| Use front shape as mask | `Ctrl Alt M` |
| Enter group / edit path or text | `Enter` |
| Select parent | `Shift Enter` |
| Show / hide | `Ctrl Shift H` |
| Lock / unlock | `Ctrl Shift L` |
| Flip horizontal / vertical | `Shift H` / `Shift V` |
| Nudge | arrow keys (`Shift` for 10×) |

## Arrange

| Action | Keys |
| --- | --- |
| Bring forward / to front | `Ctrl ]` / `Ctrl Shift ]` |
| Send backward / to back | `Ctrl [` / `Ctrl Shift [` |
| Align left / h-center / right | `Alt A` / `Alt H` / `Alt D` |
| Align top / v-center / bottom | `Alt W` / `Alt V` / `Alt S` |
