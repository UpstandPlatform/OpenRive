# Keyboard shortcuts

These are the default bindings from the editor action registry. Every shortcut
can be changed: press `Shift+/` (or `Ctrl+/`) to open **Keyboard shortcuts**,
click a shortcut and press the new keys. Custom bindings are saved in your
browser.

The notation matches the shortcuts dialog. On macOS, `Ctrl` means `⌘`
(Command), `Alt` means `⌥`, and `Shift` means `⇧`. Actions marked **Design** or
**Animate** are available in that editor mode; the same key can therefore run a
different action in each mode.
